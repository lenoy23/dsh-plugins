# Озвучка ответов (voice-tts)

Добавляет в DSH озвучивание ответов агента русским голосом Windows.

## Что делает

- У каждого готового ответа агента появляется кнопка с динамиком — рядом с «копировать» и «ветка».
- В шапке беседы есть выбор голоса: Светлана, Дмитрий (живые нейроголоса) или Irina (офлайн).
- Нажатие синтезирует речь и проигрывает её в браузере. Повторное нажатие останавливает озвучку.
- Выбор голоса запоминается в `%DSH_HOME%\voice-tts.json` и переживает перезапуск.

## Два движка

| Движок | Голоса | Звучание | Сеть |
|---|---|---|---|
| `neural` (по умолчанию) | Светлана, Дмитрий | Живая речь | Нужна |
| `sapi` | Irina | Робот | Не нужна |

Нейроголоса — это те же голоса Microsoft, которыми Edge читает страницы вслух. Старый голос Windows оставлен как запасной: если сети нет, плагин сам переключается на него.

## Как устроено

Синтез выполняется на стороне хоста:

1. Браузер отправляет текст ответа на `POST /api/voice-tts/speak`.
2. Хост очищает Markdown и вызывает `edge-tts` (Python) либо `System.Speech`.
3. Браузер проигрывает полученные байты (MP3 или WAV).

Маршруты зарегистрированы через сервис `connection`, поэтому запросы проходят ту же проверку подлинности браузера, что и остальные эндпоинты DSH. Текст в команды не подставляется — он передаётся через временный UTF-8 файл.

## Настройки

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `engine` | `neural` | Движок синтеза |
| `voice` | `ru-RU-SvetlanaNeural` | Голос по умолчанию |
| `rate` | `0` | Темп в процентах (-50…100) |
| `pitch` | `0` | Высота тона в Гц (-100…100) |
| `fallbackToSapi` | `true` | Переключаться на офлайн-голос при сбое |
| `sapiVoice` | `Microsoft Irina Desktop` | Голос офлайн-движка |
| `maxChars` | `4000` | Предел длины текста |

Список всех нейроголосов (318 языков и вариантов):

```powershell
python -c "import asyncio,edge_tts;print('\n'.join(v['ShortName'] for v in asyncio.run(edge_tts.list_voices())))"
```

## Ограничения

- Нейроголосам нужен интернет; без него работает только Irina.
- Markdown-разметка, блоки кода и ссылки не читаются — только проза.
- Синтез не потоковый: ответ озвучивается целиком, обычно за 1–5 секунд.
- Ответ, состоящий только из кода, озвучить нечего — кнопка сообщает об этом.

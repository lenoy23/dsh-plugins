# Озвучка ответов

Читает ответы агента вслух русским голосом Windows и добавляет в строку действий каждого готового ответа кнопку с динамиком.

## Зачем

DSH умеет распознавать речь (голосовой ввод), но не умеет её синтезировать: служба `speechToText` описывает только распознавание, а `System.Speech`/SAPI на хосте не используется ни одним встроенным плагином. Этот бандл закрывает вторую половину разговора — ответ агента можно услышать, не читая.

## Что делает

- Регистрирует маршрут `POST /voice-tts/speak`, который принимает `{ "text": "…" }` и отвечает WAV-байтами.
- Синтезирует речь локально через `System.Speech` (`SpeechSynthesizer` + `SetOutputToWaveFile`), голос по умолчанию — `Microsoft Irina Desktop` (`ru-RU`).
- Добавляет в слот `conversation.chat.assistant-actions` кнопку «Озвучить ответ». Она берёт прозу ответа из снапшота Chat, а не из DOM, поэтому разметка и группировка сообщений остаются нетронутыми.
- Повторное нажатие останавливает воспроизведение; уход со страницы освобождает аудио.

## Как это работает

1. Клиентский модуль подписывается на снапшот Chat и для нужного `messageId` собирает текстовые блоки ответа.
2. Markdown вычищается: блоки кода, ссылки, изображения и маркеры разметки не читаются.
3. `fetch('/voice-tts/speak')` отправляет текст на хост.
4. Хост пишет текст в временный UTF-8 файл, запускает сгенерированный PowerShell-скрипт и возвращает WAV.
5. Браузер проигрывает полученный `Blob` через `Audio`.

## Безопасность и устойчивость

- Маршрут регистрируется через `ctx.connection.fetch.register`, поэтому действует общая проверка подлинности браузера (loopback `Host`, совпадающий `Origin`, подписанная cookie сессии). Отдельный незащищённый HTTP-эндпоинт не создаётся.
- Текст никогда не подставляется в командную строку: он попадает в PowerShell только через файл, а имя голоса экранируется.
- Длина ограничена `maxChars` (жёсткий предел 20000 символов), синтез ограничен таймаутом.
- Временный каталог удаляется в `finally` независимо от исхода.

## Настройки

`voice`, `rate`, `volume`, `maxChars` и `timeoutMs` задаются в `cordis.patch.yml` профиля и переживают обновления DSH.

## Ограничения

- Платформа — только Windows.
- Синтез не потоковый: ответ озвучивается целиком после завершения синтеза.
- Ответ, состоящий только из кода или вызовов инструментов, озвучить нечего — кнопка сообщает об этом.
- Это озвучка по запросу; автоматическое чтение каждого ответа и голосовой диалог — следующий шаг.
